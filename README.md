# Я — Це Ти — Web

JS-порт психологічної/sci-fi термінальної гри "Hermes" ("Я — Це Ти").

**Оригінал (Python):** [github.com/santoni-star/ya-eto-ty](https://github.com/santoni-star/ya-eto-ty)

## Фази портування

| Фаза | Статус | Опис |
|------|--------|------|
| 1 | ✅ | HTML/CSS термінал, dispatch, історія команд |
| 2 | ✅ | Віртуальна ФС + команди (ls, cat, cd, find, grep) |
| 3 | ✅ | Ресурси (CPU/RAM/CTX), таймер, тіки, події |
| 4 | ⬜ | Create/talk/dialog wheel + archetypes |
| 5 | ⬜ | Hack minigame + sub-agents |
| 6 | ⬜ | Endings + quests + roast + admin manifest |
| 7 | ⬜ | Save/load, responsive, GitHub Pages deploy |

## Команди (Phase 1-3)

- `help` — довідка
- `status` — стан системи
- `ls`, `cat`, `cd`, `pwd` — файлова система
- `find`, `grep` — пошук
- `scan`, `ping` — мережа
- `ps`, `df`, `du` — системна інфа
- `clear` — очистити
- `spawn`, `agents`, `terminate` — субагенти (після відкриття)

## Запуск

Просто відкрий `index.html` у браузері або залий на GitHub Pages.
